### 例夜、构筑与持续状态

路径：开场战 → 夜市 → 门压战 → 香案事件 → 上楼战 → 休整/风险战 → 陌名事件 → 双压战 → 休整 → 三阶段头目。选择任一分支均经过十节点，战后三选一不额外计为地图节点。

- 初始守香为晚带领的既有值夜班五人（晚、铁肩、朱砂、乡勇、弩手），夺名为十六白衣；该班底只在入夜建立。普通跨场只保留幸存者及实际生命，不暗中复活。
- 胜利公开奖励最多 8 香火、4 名分，受 60/12 上限约束，实际增量写入账本。休整回复幸存者25%最大生命、4香火、1名分。失败仅有一次明示的免费复香：重试当前场，并按数据恢复战前名单及最低资源/生命。
- 构筑实际修正点册时间/收益、自然回复、维修回复、变异费用或增潮数量；装备/属性牌写入具体单位，不在下场重复加成。卡面均显示数值，普通白衣无装备槽。
- 三选一互异、只能领取一次，至少一张可用构筑，同组最多一张保命；保命始终有抽到的机会。满编且构筑封顶时仍有三张可用牌，白衣可通过上梁/破门变异方变成真实精英，保持 UID、损伤比例和一次变异限制。
- 结算保留已付款但尚未入场的增潮单位；陨落名单记录死亡时实际变异形态。若自动退守后补购导致下场原岗位超过三人，将额外单位部署到最近同职分合法空余掩体并记入 `night_redeploy`，不扣第二次费用。
- 再开新夜仅继承合法存档中的图鉴遭遇/招募解锁，不继承任何攻击、生命、装备、资源或构筑。没有第三种货币和永久数值成长。

## 3. 如何运行、如何打开调试项

双击仓库 `run.command`，或使用 Godot 4.7.2 打开 `project.godot`。当前启动为入夜界面，选守香或夺名例夜；凶夜按钮明确禁用。

```sh
./run.command
./tools/test.sh
./tools/godot.sh tests/P5Suite.tscn -- --capture
python3 tests/test_boot_guard.py --godot /absolute/path/to/Godot --report-prefix p5
```

Space 暂停/继续，−/+ 选择1×/2×；Q 购入、E 升级或变异、R 点册、F 修门、T 增潮。暂停决策与合法掩体部署沿用 P4，鼠标点击地面不下达移动命令。三选一和夜市的目标卡先在下拉框中选合法单位再确认。

「保存」及「保存并回入夜」记录当前节点；继续战斗恢复原场并保持暂停，按 Space 继续。存档为 `user://night_save.json`，项目自定义用户目录名为 `ye-ci`。坏档读取会显示原因并保留原内存战局；新夜会替换当前夜存档，入夜已有说明。种子可在结夜复制，但尚未提供输入种子的 P6 产品复盘。

F1/F2/F3/F4/F6/F9/F10 仍可查看网格、身高、掩体、镜头、单位、弹道、FPS。夜程中 F5/F7 被禁用，避免重置跳过当前节点；独立 `Combat.tscn` 保留原调试能力。

- 凶夜未开放；正式随机夜程与25–40分钟目标留待后续，S2按允许的延期条款记录。

- 本地单存档，没有槽位管理、云端账号或版本迁移。实体手柄、Windows真机、跨平台字体与中档Windows性能未验证；现有Windows导出仍为P0历史包，P5请运行源码。
