## 3. 如何运行与复核

在 Godot 4.7.2 stable 导入根目录的 `project.godot` 并按 F5。从标题选择「开始 → 例夜 → 守香」，进入第一战。空格暂停，HUD 按钮继续，A/D 或鼠标中键平移。点击在场人或鬼可查看完整卡。从夜程或标题进入图鉴，选已列名的条目，点「列名余文」。F6 切换房间名，默认关闭。键鼠复核使用 1920 × 1080 原生视口，例夜和图鉴测试使用独立存档。

```sh
python3 tools/p9_verify.py --native --script tests/P11VFXSuite.gd
python3 tools/p9_verify.py --native --script tests/P11WorldArtSuite.gd
python3 tools/p9_verify.py --native --script tests/P11StorySuite.gd
python3 tools/p9_verify.py --native --realtime --script tests/P11Experience.gd
python3 tools/p11_audio_acceptance.py --driver CoreAudio
python3 tools/p9_verify.py --script tests/P11Compatibility.gd
```

## 5. 已知缺陷与未验证项

- 150 单位尚有掉帧和模拟滞后。以上是本机短窗实测，不能推算 Windows 帧耗、长局内存或真人操作手感。
- 默认切片里殿门位于 x=960。它在设计图中更靠右；本版保留实际地形和锁定镜头，没有为拍图搬门。四排鬼潮密集时会彼此遮挡，最深排的小配饰，以及门后远处的角色轮廓，是原图复审的重点。
- 三条结局由可复现夹具验证。普通玩家的自然到达率、完整凶夜时长与音效盲听辨识率未测。64 张静帧的最终美术签收仍在设计方。
- P8 与旧档测试进程在断言通过、退出时仍打印 ObjectDB／资源释放提示。该信号未测出长局内存增长，需保留排查。三档最终原生计时运行无脚本错误。
