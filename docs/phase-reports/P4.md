# P4 决策指令与 G0 阶段报告

验收日期：2026-11-17，Asia/Shanghai。环境：macOS 26.5.1 / arm64 / Apple M2 Pro，Godot `4.7.2.stable.official.ed1daf0bf`，Compatibility / OpenGL。本文记录本地源码、固定步长模拟、真实引擎渲染和合成输入事件的结果，不代表 Windows 真机、实体手柄或发行验收。

## 1. 本阶段目标是否达到（是/否）

**是。P4 K1–K12 与 G0 总表六条通过本地自检，达到本阶段的「G0 规则能玩」。没有开始 P5。**

守香与夺名在同一张正门庭地图、同一个 `CombatSimulation` 和 `Formula` 上完成战局。守香支持暂停购入、合法掩体部署、升级、占位香器、晚点册及真实内侧修门；夺名支持白衣上梁/破门变异和有限增潮。开战前选席，结算给出胜负原因及资源，并支持再战或重新选席。

| 完整验收战 | 结果 | 模拟时长 | 首次破门 | 结束资源 |
| --- | --- | ---: | ---: | --- |
| 守香：晚 H01、铁肩 H09、朱砂 H17 + 两杂兵 | 守至天亮，胜利 | 240.000 秒 | 外门 112.317 秒 | 香火 12.8、名分 8.0 |
| 夺名：白衣 G01、力士 G12、缢鬼 G09 | 持续占领名册房，胜利 | 164.150 秒 | 外门 44.117 秒 | 香火 8.698、名分 2.954 |

夺名本场以占领获胜，**没有抽干名分**。守香使用六次成功修门决策延长防线；夺名在开局把白衣变为力士、92.017 秒把另一名合格白衣变为缢鬼。完整指令、拒绝原因、资源快照、破门/上楼事件与结算原文均保存在 [渲染结果](p4-render-results.json)。修门路径不通时被拒绝，不扣费。

P3 无玩家干预基线复测仍为：空图 **47.183 秒**，默认坚守首次入房 **174.867 / 178.700 秒**。主动变异的夺名进攻更早破门、入房，是正式决策的结果，不能用它替代 P3 的默认坚守计时。

点册原来是 P2 的位置/读条接口，本轮接入付费与净化；正式 P4 不再自动免费施放，旧开发入口也必须经过收费验证。读条中受伤、移动、换层/超距或目标死亡会打断；已经花费的香火不退，也不发完成奖励。其他单位仍继续执行同一战斗模拟。

购入分为付费预留和部署确认，非法部署不会二次扣钱；取消只退一次。部署时再次检查岗位、职分、具名唯一性及人数。所有正式命令在结算后拒绝，资源、计时和战斗停止。

本轮未调整 P3 的路线、波次、速度和门障耐久。修门、名册占领/回复速率、自然香火、人数上限等为本阶段首次落表的可调初稿，尚未进行多策略/多玩家平衡调参。夺名本例 2 分 44 秒，早于普通场推荐 3–6 分钟，但在 4 分钟天亮上限内提前达成目标；不能据两条脚本宣称普通战斗时长分布已完成验收。

## 3. 如何运行、如何打开调试项

双击根目录 `run.command`，选守香或夺名即可进入对应正式战局。当前 Windows 导出仍是 P0 历史包，P4 应运行源码。

```sh
./run.command
./tools/test.sh
./tools/godot.sh tests/P4Suite.tscn -- --capture
python3 tools/encode_p4_replays.py
python3 tests/test_boot_guard.py --godot /absolute/path/to/Godot --report-prefix p4
```

- Space 暂停/继续；`-` 为 1×，`+` 为 2×，或点顶栏按钮。点击单位、打开决策菜单自动暂停。关闭后按 Space 继续。
- 守香 Q 购入 → 合法掩体岗位部署，右键取消并退款；E 升级/占位香器；R 选晚和合法点册目标；F 选受损门修理。
- 夺名点击白衣，E 上梁/破门变异，T 打开增潮菜单。无需下达逐只走路指令。
- A/D、方向键、中键拖动平移镜头；底栏可开关边缘滚动。暂停时镜头仍可移动。
- 手柄 Start 暂停，左右摇杆按下切 1×/2×，肩键切单位，X 打开指令，方向键菜单焦点、A 确认、B 返回。实体验证边界见第 5 节。
- F5 会退出正式会话并重置无交战路径实测；F7 可切默认坚守计时、40/80 密度预设、源头刷精英。调试与正式胜负分开，避免 P4 会话冻结 P3 测试。
- F1/F2/F3/F4/F6/F9/F10 继续提供网格、尺寸、掩体、镜头、状态、弹道和 FPS。镜头与单位尺寸不随打开面板改变。

手工复现可先守香暂停打开购入，故意选院心、右键取消，再部署到门内岗位；点击人物检查 E 预览并确认。待门受伤用 F 维修，观察维修者行走与耐久回升。待目标进入晚的合法室内范围后点册，恢复时间观察成功/伤害打断。夺名在源头白衣推进后暂停选中，分别试上梁/破门与增潮冷却。两席都可等待真实结算并使用再战/选席按钮。
