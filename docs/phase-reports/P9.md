## 3. 如何运行、如何打开调试项

双击仓库根目录的 `run.command`，或用 Godot 运行 `project.godot`。标题选「开始例夜」进入坐席选择。F1 网格、F2 身高、F3 岗位/退守线、F4 镜头框、F10 帧率可用于复核。

**键鼠例夜。** 标题选守香，点击当前可进节点。战中按 Q 或点击购入，核对香火、生命和攻击后选卡，再点高亮的室内岗位。点单位看卡，Space 停走，+ 切 2 倍速；中键拖动或 A/D 平移。胜场后必须领取三张之一，下一节点可在夜市按明价交易或离开。失败时在复香界面选择结夜，查看先断的线与种子。Esc 打开暂停菜单。左键拖框用于多选查看，夺名另可对符合条件的所选鬼物执行批量变异。

**手柄例夜。** 方向键移焦、A 确认、B 返回。从标题选择开始、守香和首节点。X 打开指令，选择购入、选卡，再确认合法岗位。肩键轮选单位，右摇杆平移，Start 切换停走，按右摇杆切 2 倍速。Back 打开暂停菜单。奖励、夜市、复香、结算都沿菜单焦点推进。设置支持修改绑定，以上为默认键。

隔离运行使用临时源码副本与独立存档。下面两条从正式标题驱动同一套界面；专项复测分别保留原生窗口与显示断言。

```sh
./run.command
python3 tools/p9_verify.py --input mouse
python3 tools/p9_verify.py --input pad
python3 tools/p9_verify.py --native --script tests/P9BattleUI.gd
python3 tools/p9_night_qa.py
python3 tools/p9_verify.py --native --script tools/p9_shell_smoke.gd
# 第二进程读取首轮隔离存档，替换为上一条命令打印的输出目录
python3 tools/p9_verify.py --native --script tools/p9_shell_smoke.gd --state <首轮输出目录>/state
```
