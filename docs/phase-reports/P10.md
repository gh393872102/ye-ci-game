### 十二条科仪怎样改变一夜

| 科仪 | 实际规则 | 关卡或奖励倾向 |
|---|---|---|
| R01 例夜安香 | 采用基准数值，手搓例夜固定使用 | 标准分布 |
| R02 中元放灯 | G10 更常入潮；水巷中攻击与拖曳提高 30%，成功超度多得 1 名分 | 水巷、河灯与河灯盏 |
| R03 祭灶 | 香火回复乘 1.5；火技落点留火 2 秒，可伤双方。硝青保留友军豁免 | 灶房、符法与控制。完整灶塘放大火区，破坏后回到普通半径 |
| R04 接寿 | 须保护「尚有寿数的人」。其死亡直接结夜；实际升级、装备与生命跨战保存。验收从 48／55 生命、升阶 1、装备 I17 的胜场一路读档进入下一战，状态一致 | 护卫人物，含铜锣 |
| R05 开面 | 无面单位受灯恐惧时间乘 1.5，面匠暂面影响名分 | 灯、面匠、夺面使 |
| R06 祭桥 | C07 必出，桥断后该路增援实际停止 | 石桥、守桥和阻路奖励 |
| R07 禁声 | 钟锣啼哭仍能揭隐；哭夜受反噬，铜锣依特性豁免。禁声廊内声音传播半径提高 | 禁声廊、潜行与反潜 |
| R08 列名夜 | 点册时间缩短 25%，首战即可出现抹名或留白压力 | 名面、点册、超度 |
| R09 寒食 | 禁止火技，香火回复乘 0.6，物理与符封加强 20% | 武卫、符师，降低灶火类权重 |
| R10 上梁 | 上层被敌方占据、持续无人争守达到 6 秒后触发独立失败线 | 回廊、缢鬼、童亡与机关 |
| R11 游神 | 借神由 12 香火降至 7，仍需 1 名分。空位神概率由 15% 至 35%；48 组同种子对照实际为 9 次与 16 次 | 借名事件、无册奖励 |
| R12 无册渗透 | 开战即渗名，每秒下降 0.025；头目固定 B03，实际生成无册谱 G32 | 侧巷、阴缝、无册系 |

### 十二块设计

| 块 | 默认通路 | 上层联系 | 破坏与失败线 |
|---|---|---|---|
| [C01 正门庭](../../data/levels/chunks/C01.json) | 潮源 → 中层废台 → 外门 → 外庭拒马 → 内门 → 二进庭 → 主殿门厅 | 主殿内宽梯接二楼回廊，庭院供设阻和转进。 | 外门退到庭内，主殿门破则退至楼梯。 |
| [C02 侧门巷](../../data/levels/chunks/C02.json) | 二进庭巷口 → 侧门 → 主殿侧门厅 | 内巷两端各有斜阶，后口通往门厅和主楼梯。 | 侧门破，潮从巷后向门厅夹入。 |
| [C03 二楼回廊与梁](../../data/levels/chunks/C03.json) | 主殿楼梯 → 二楼回廊 → 梁梯 → 吊钟与后阁 | 主梯和后梯连地面，梁梯由二楼通到上层钟房。 | 梁梯失守可从后梯进入名册房。 |
| [C04 名册房](../../data/levels/chunks/C04.json) | 下楼口 → 名册房 → 后侧出口 | 从二楼香案旁的后梯下到名册房，再退可至后门。 | 名册房失守或名册香火熄灭，守香失败。 |
| [C05 水巷](../../data/levels/chunks/C05.json) | 外庭水道 → 闸板 → 回岸 | 水道两头有下堤斜阶，水道自身不通二楼。 | 闸板失守后水鬼可贴着水面拖拽并从内庭出水。 |
| [C06 井口](../../data/levels/chunks/C06.json) | 外庭拒马 → 井栏 → 井旁缺口 | 井底只形成落差，后侧缺口仍可向主梯退。 | 井栏毁后，脚踩井口的兵会受到坠井伤。 |
| [C07 石桥](../../data/levels/chunks/C07.json) | 二进庭前石阶 → 石桥 → 落阶至内庭 | 桥面是石阶相连的中层，地面旧路可绕行。 | 桥墩崩塌会断桥；祭桥时来自同一路的增援停止。 |
| [C08 戏台](../../data/levels/chunks/C08.json) | 二进庭西端 → 台沿幕架 → 主殿门侧 | 台沿与石阶形成小高差，主楼梯继续通二楼。 | 幕架破后潮从台沿直接靠近门厅。 |
| [C09 侧殿](../../data/levels/chunks/C09.json) | 残墙 → 侧殿短梯 → 回廊前端 | 短梯从二进庭接到延长的回廊，与主梯共用二楼。 | 残墙失守，二楼可从侧殿被牵制。 |
| [C10 阴缝](../../data/levels/chunks/C10.json) | 内庭暗裂 → 符封口 → 门厅前沿 | 缝设在内庭暗角，潮从此加入去向主殿的地面路。 | 缝未封会按间隔补潮，符封期间暂停。 |
| [C11 灶房](../../data/levels/chunks/C11.json) | 后廊隔断 → 火塘 → 楼梯前廊 | 火塘占用一层侧室，后廊与主楼梯连通。 | 隔断破时潮能进灶房，火仍可能殃及两边。 |
| [C12 禁声廊](../../data/levels/chunks/C12.json) | 回廊钟口 → 廊门与隔扇 → 二楼香案 | 廊连二楼楼梯口与后室，能沿主梯及后梯通行。 | 廊无单独终局线，失去隔扇后会暴露读条岗位。 |

## 3. 如何运行、如何打开调试项

运行仓库根目录的 `./run.command`。标题「开始守夜」可选编制例夜、经典例夜或凶夜。凶夜支持指定种子、科仪和三项可叠加修饰。留空种子会生成新的种子，随机科仪由该种子决定。凶夜开夜香火较例夜少 4 点，例夜有一次免费复香。

观祭中选择科仪，打开「编排祠场」组合关卡块、头目和无册修饰。再选编制、初始合法岗位、香火、名分、凶度并开始。R12 要求 B03，切走 R12 会恢复先前自选的舞台。战斗中按空格停走，A/D 或中键拖拽平移，F1/F2/F3/F4 分别查看网格、身高、岗位和视野。程序计时使用固定步长；下列原生脚本将工程、局中存档、图鉴与回放放在独立临时目录。

```sh
python3 tools/p9_verify.py --native --script tests/P10Host.gd
python3 tools/p9_verify.py --native --script tests/P10RitualSuite.gd
python3 tools/p9_verify.py --native --script tests/P10Chunks.gd
python3 tools/p9_verify.py --native --script tests/P10StageSuite.gd
python3 tools/p9_verify.py --native --script tests/P10SaveSuite.gd
```

## 5. 已知缺陷与未完成项

- 种子 4105 的坚守时间为 193.70 秒，比 3 分钟参考值长 13.70 秒；满足 P10「不得早于 2 分钟」的硬门槛。该数据来自一组指定守军与默认障碍。
- 两组同夜事件使用缩短验收夜。自然随机凶夜的长期胜率、两席整夜平衡和包含玩家思考的 25–40 分钟真人游玩时长仍待验证。
- 运行与截图取自 macOS 本机。战场保持远镜头简模，P8 的 64 张角色画像继续列为精绘占位。手柄已按甲方要求暂缓，本阶段交付源码与测试证据。
