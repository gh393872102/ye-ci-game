### 自审与反例

正式战斗模拟按同一地图与种子做四组各16场配对。逐局名单、部署、时间、失败原因和重跑方法见[实验记录](../../tools/faction_baseline/README.md)。原判定下，八鬼进攻时守方0/16胜，等人数时4/16胜。改用试炼守册目标后分别为0/16、5/16。等人数也未控制招募造价。默认夜程继续使用原胜负规则。首轮记录的是开局纯度，技能导致的临时改派须另统计。

奇人三人全活，旧规则四次都在16.05秒判负。试炼允许任何存活的本方具名守军驻守，奇人对无名潮能撑满240秒；对习俗厉仍会被占，对无册谱仍会熄册。符法司也有明显的站位差：六对六原站位在222.267秒丢册；改成三人守册、三人守厅门，同一对手下守满240秒。以上都是存在性证据，尚不足以推断普通玩家胜率。

### 四个池子的取舍

- 装备。八种起始编制各提供三件可选物。守香司可比较册底针保护读条和河灯盏的水中加速；武卫司可在封门和护身间取舍。三件初始物取自现有目录，本轮没有增报物品数量。
- 进化。继续复用花香火、保留身份与伤损的变异命令。无名潮试炼新增可玩的「入水」路线，白衣在外院水段付10香火变水鬼，旱地和预算不足时拒绝。转成习俗厉后计混编。
- 融契。仍沿用材料、单位与次数限制。首轮需监测纯系玩家是否只能靠跨系配方解决门障；在同系替代路线通过之前，不把跨系合成算进纯系胜局。
- 属性特征。优先在实际遭遇里验证护门、揭示、抗打断、破障和水中拖拽。后续候选仅在现有单位上产生可观察的动作或取舍时入池，并记录扩池前后的出现率与跳过率。

### 美术与规模

铁肩从倚盾站岗改为肩顶门盾。保留原短须、旧甲、盾面和祠堂身份，重绘受力姿态并调整图鉴脸部区域。此图为一张游戏候选立绘，尚待720p图鉴和战场同屏读图复验。本轮的无窗口战斗通过角色、技能、门障和换边路径；模拟60Hz与实际渲染60帧分别验收。下一轮优先测普通夜程同预算、多种子开局，保存最差路线；于1080p记录大潮时帧耗P50/P95/P99、活跃单位与特效量，再决定扩大同屏规模。

### 追加复审：后排部署

增补同人数、守册目标、优先册房岗位的16场，总数80场。五组各16场中守方依次获胜0、4、0、5、7场。最后一组四司分别为1/4、3/4、1/4、2/4。八个阵营都观察到至少一个纯初始阵容胜例；攻方在其中多组均有胜例。因固定种子、预设初始编制且未走招募经济，不把这些胜例登记为普通游戏已平衡。
