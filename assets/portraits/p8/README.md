# P8 独立立绘占位资源

本目录的 H01–H32、G01–G32 共 64 张 PNG 均是独立生成的高规格占位立绘，分辨率 1024×1536。每个角色各调用一次内置 imagegen 生成；不是拼图切片、换色 SVG，也不作为战场精灵使用。T01–T04 是兵种模板，不提供虚构独立立绘。

`prompts.json` 保留每张提示词，`manifest.json` 与逐项 `.meta.json` 保留来源路径、尺寸、SHA-256、占位状态及逐项替换计划。64 张成功生成共使用 64 次调用；G09 首次描述被工具拒绝，改为双手攀握绳索、头颈自由且无伤害的构图后另调用一次，因此总尝试数是 65 次。原始生成文件保持不变，项目文件是原 PNG 的复制。

视觉复核使用原生 1920×1080 联系表，每组直接展示八张独立源图；全部 64 张已逐组查看。人物服装、器物、年龄、姿态与鬼物轮廓分别设计。图中不使用文字标签作为身份依据，角色 ID 与业务定义仍取仓库 CSV。原生完整卡、720/1080 布局、八对同骨架辨识的独立验收证据由 P8 验收套件记录。

`face_state.gdshader` 只在卡片显示有面／无面状态与图鉴线稿阶段；不修改 PNG。`codex_silhouette.gdshader` 仅将真实战场形体显示为未知剪影。战场形体来自 `src/units/UnitAppearance.gd` 的八种人类骨架和八种鬼怪骨架，沿用实际 P8 profile 身高，保留生命条、选择框、读条与灰军覆盖层。

全部 64 项都需要在最终美术阶段逐 ID 替换。替换时保持路径与身份一致，重新核对面部区域、有面／无面表现、图鉴线稿／彩稿阶段、720/1080 卡片以及原画与战场识别物的一致性。P8 的高规格占位完成不代表最终 1.0 美术完成。

P9 复核（2026-11-18）：H01–H32、G01–G32 全部沿用本清单，仍为 64 张待精绘、0 张批准为终稿。P9 新绘的场景与器物用于菜单和夜程，不抵扣这些角色。
